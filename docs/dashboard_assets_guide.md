## 3. Platform Roles

### Google Sheets

Used for:

- original cleaning workflow
- engineered columns
- pivot-table analysis
- first dashboard layer

Best for:

- showing the analytical process
- reviewing formulas and pivots
- demonstrating the foundation of the project

### Looker Studio

Used for:

- executive dashboard presentation
- fast KPI scanning
- high-level trend and regional analysis

Best for:

- final presentation summary
- reviewer-friendly dashboard overview

### Tableau Public

Used for:

- multi-page storytelling
- deeper interactive analysis
- profitability and loss-risk drill-downs
- customer and shipping analysis

Best for:

- complete final dashboard review
- exploring filters and detailed business relationships

## 4. Recommended Review Order

1. Open the Google Sheets workbook to understand the data preparation and pivot logic.
2. Open Looker Studio for the executive summary view.
3. Open Tableau Public for the most complete analytical narrative.
4. Use the exported PDFs and screenshots as backup visual evidence if live links are unavailable.

## 5. Scope Separation Note

This guide belongs to the outer `SuperStore_Analysis/docs` folder because it covers all dashboard platforms.

The inner Tableau docs folder is narrower and should only document the Tableau workflow and Tableau-specific assets.
